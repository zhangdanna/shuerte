# 舒尔特方格闯关小游戏 · 游戏大纲

> 版本 v0.1 ｜ 平台：微信小程序 ｜ 定位：专注力训练 + 闯关挑战

## 1. 产品定位

| 项 | 内容 |
| --- | --- |
| 一句话描述 | 用最短时间按顺序点完 N×N 方格里的数字，逐关进阶的专注力训练小游戏 |
| 目标用户 | 学生 / 上班族，碎片时间 1~3 分钟，享受"比上次更快"的成就感 |
| 核心体验 | 3 秒上手 · 单局 20~90 秒 · 每局都有可量化的进步 |
| 核心循环 | 选关 → 倒计时 → 专注点击 → 即时评级 → 拿星解锁 → 再来一局 |

**三条设计红线**（决定用户是否留下）：

1. 单局时长 < 90 秒，随时可中断，不产生"玩不完"的心理负担。
2. 每局结束必须给出**可比较的数字**：用时、星级、错误数、是否破纪录。
3. 永远存在"下一件想做的事"：下一关 / 每日挑战 / 刷新个人纪录。

## 3. 关卡设计

### 3.1 难度维度（正交组合，供后续扩展）

| 维度 | 取值 | 说明 |
| --- | --- | --- |
| 尺寸 | 3×3 / 4×4 / 5×5 / 6×6 / 7×7 / 8×8 | 基础难度，决定方格数量；本项目采用「逐关递增」的阶梯 |
| 图案 | 卡片造型：方形卡 / 圆形卡（圆盘扇环分区）/ 生肖卡（整卡生肖轮廓 + 轮廓内 Voronoi 分格，墨色线稿风） | 扫视难度递增：圆形去掉直角参照，生肖卡形状无规则、更难落眼 |
| 排列 | 随机 / 螺旋 / 蛇形 | 排列规律影响视觉搜索难度 |
| 顺序 | 正序 1→N / 倒序 N→1 | 倒序天然更难 |
| 模式 | 普通 / 双色交替（红奇数、蓝偶数）/ 奇偶分离 | 增加规则负担 |
| 干扰 | 无 / 静默变位（每 5 秒重排）/ 限时 / 数字渐隐 | 高阶玩法 |

> **实现原则**：每关只需在配置里声明用了哪些维度，玩法逻辑由"模式策略"统一处理，新增维度不改核心代码。

### 3.2 难度档结构

| 档位 | 尺寸（逐关递增） | 卡片造型与格子排布 | 关卡数 | 解锁条件 | 设计意图 |
| --- | --- | --- | --- | --- | --- |
| 初级 | 3×3 → 8×8（走两遍） | 方形卡 · 常规方块网格 | 12 | 默认解锁 | 5 秒就能通关，开局零流失 |
| 高级 | 3×3 → 8×8（走两遍） | 圆形卡 · 整块圆盘按半径分圈、角度分格，格子是扇环沿圆边排一圈 | 12 | 累计 8 星 | 去掉直角参照，扫视难度上一个台阶 |
| 困难 | 3×3 → 8×8（走两遍） | 生肖卡 · 整张卡是生肖轮廓（12 生肖依次出场），格子在其中按 Voronoi 划分成不规则多边形 | 12 | 累计 16 星 | 形状干扰 + 无规则参照，硬核挑战 |

> 界面上只呈现「初级 / 高级 / 困难」三档难度，卡片造型是各档的固定皮肤，不作为分类展示。
> 档内把尺寸阶梯走两遍，第二遍的星级阈值与限时同步收紧 3%（最低 70%），形成档内递进。
> **后续扩展**：新增档位只需往 `TIER_BLUEPRINTS` 加一项；也可以在新档里改用倒序 / 双色 / 变位等规则难度，而不必继续放大尺寸。

### 3.3 星级阈值与限时

| 尺寸 | 3 星（快） | 2 星（达标） | 限时（超时即失败） |
| --- | --- | --- | --- |
| 3×3 | ≤ 6s | ≤ 9s | 15s |
| 4×4 | ≤ 12s | ≤ 18s | 25s |
| 5×5 | ≤ 25s | ≤ 36s | 40s |
| 6×6 | ≤ 42s | ≤ 58s | 60s |
| 7×7 | ≤ 65s | ≤ 88s | 85s |
| 8×8 | ≤ 95s | ≤ 125s | 115s |

**错误修正**：0 错误额外 +1 星（上限 3 星）。即"速度快"与"零失误"是两条并行的追求路线。

**阈值口径**：阈值只跟尺寸有关（按尺寸查表），关内不再收紧；难度差异由尺寸、卡片造型与档位系数承担。

**限时口径**：限时约等于 2 星阈值的 1.5 倍，参考舒尔特训练标准设定。限时是"别卡死"的兜底，真正的时间压力来自星级阈值与失误罚时。超时即失败，不记录成绩、不解锁下一关。

### 3.4 解锁规则

- **档内**：通关上一关即解锁下一关（1 星即可推进，不卡进度）。
- **跨档**：用累计星星数做门槛，鼓励回刷高星。
- **已解锁关卡**：可无限次重挑战，只记录最好成绩，"刷星"是核心长期玩法。

## 4. 通关规则

| 场景 | 规则 |
| --- | --- |
| 开局 | 3-2-1 倒计时，倒计时结束才开始计时（避免手忙脚乱） |
| 目标 | 按顺序点击 1 → N，界面顶部常驻显示"当前目标数字" |
| 点击正确 | 短促"叮"声 + 格子标记为已完成 + 目标数字推进 + 轻微缩放反馈 |
| 点击错误 | 低沉"嗡"声 + 短震动 + 格子红色闪烁 + 错误计数 +1 + **罚时 1.5s** |
| 计时 | 以 `Date.now()` 差值计算，不累加，保证精度 |
| 通关 | 点完最后一个数字，立即进入结算，播放通关特效 |
| 失败 | 每关都有限时，倒计时归零未完成即失败；失败不记录成绩、不解锁下一关，必须重打本关 |
| 中途退出 | 视为放弃，不记录成绩、不消耗每日挑战次数（但每日挑战退出算已用一次） |
| 暂停 | 允许暂停，暂停期间停止计时（UI 完全遮挡方格防作弊） |

**关于错误罚时的取舍**：单纯记错误数容易被"乱点流"绕过——只要手速够快，蒙也能过关。加 1.5s 罚时后，"乱点"的时间成本高于收益，玩家会自然转向"看准再点"，这正是舒尔特训练的核心价值。

## 5. 奖励机制

### 5.1 短期奖励（每局即时）

- 星级评定（1~3 星），结算页星星逐个弹出动画
- 破纪录标记：本关最快 / 全服最快 / 今日最快
- 连击奖励：连续 3 局不失误，弹出"专注之星"提示

### 5.2 中期奖励（关卡与章节）

- 首通奖励：首次通关某关额外获得 1 颗"章节星"
- 章节满星宝箱：某章全部 3 星 → 解锁主题皮肤 / 方格样式
- 星星总量里程碑：每满 20 星解锁一个新徽章

### 5.3 长期奖励（成就系统）

| 徽章 | 达成条件 | 心理驱动 |
| --- | --- | --- |
| 初出茅庐 | 完成首次对局 | 降低启动门槛 |
| 零失误 | 单局 0 错误通关 5×5 | 追求精准 |
| 闪电手 | 5×5 用时 < 20s | 追求极限 |
| 坚持不懈 | 连续挑战 7 天 | 形成习惯 |
| 全章满星 | 任一章节全 3 星 | 完美主义 |
| 方格之王 | 7×7 3 星通关 | 身份认同 |

### 5.4 每日奖励

- 每日挑战：固定种子（当天所有玩家同一套数字），保证公平可比
- 连续签到：第 3 / 7 / 15 / 30 天给特殊徽章，断签不清零但重置连击倍数
- 每日首次通关额外 +1 星（小额但每天都有）

## 6. 留存与增长设计

| 机制 | 触发点 | 心理驱动 |
| --- | --- | --- |
| 每日挑战 | 大厅首屏置顶 | 稀缺性 + 公平比较 |
| 连续签到 | 每日首次进入 | 损失厌恶（不想断连） |
| 破纪录提示 | 结算页 / 大厅 | 自我超越 |
| 排行榜 | 结算页"你排第 37 名，超过 82% 玩家" | 社会比较 |
| 成就收集 | 个人中心徽章墙（灰色未解锁可见） | 收集欲 + 完成欲 |
| 分享海报 | 结算页 / 破纪录时 | 炫耀 + 拉新 |
| 一键"再来一局" | 结算页主按钮（免返回） | 降低重开成本 |

**关键设计**：结算页按钮排序为「再来一局」（主）→「下一关」→「返回」，把重开成本压到 1 次点击，这是提升局均次数的最大杠杆。

## 7. 反馈层（音效 / 动效 / 震动）

| 事件 | 音效 | 动效 | 震动 |
| --- | --- | --- | --- |
| 点击正确 | 清脆"叮"（短、高频） | 一次点击动效（缩放/淡闪），**不改变格子底色** | 无（避免频繁震动） |
| 点击错误 | 低沉"嗡" | 格子红色闪烁 2 次 + 全屏轻微抖动 | 短震动 |
| 倒计时 | 每秒"嗒" | 数字放大淡出 | 无 |
| 剩余 ≤ 35% | 无 | 计时条与剩余时间转橙 | 无 |
| 剩余 ≤ 15% | 加速"嗒" | 计时条与剩余时间转红并脉冲 | 每秒短震动 |
| 通关 | 胜利音效（上行三音） | 方格依次消隐 + 粒子/星光 + 星级弹出 | 长震动 |
| 破纪录 | 特殊音效 | 金色光晕 + 数字滚动 | 双短震动 |

**原则**：正确操作必须"爽"（即时、轻快），错误操作必须"明确但不刺耳"（不惩罚情绪，只提示方向）。

## 8. 新手 60 秒体验脚本

| 时间 | 发生什么 |
| --- | --- |
| 0~3s | 启动页 → 自动进入大厅，直接高亮「开始挑战」，无需注册登录 |
| 3~8s | 第一关 5×5，目标数字高亮提示"点击 1"，3-2-1 倒计时 |
| 8~40s | 完成首局（阈值刻意宽松，保证 3 星） |
| 40~50s | 结算页：三星 + 成就"初出茅庐" → 「下一关」高亮 |
| 50~60s | 进入第 2 关，此时已完成从"陌生人"到"有星星的人"的转化 |

**转化关键**：首局必须拿满 3 星，且在一分钟内看到第二关。之后的关卡才开始收紧阈值。

## 9. 后续可扩展方向

- 多人实时对战（同时开局，比谁先完成）
- 主题皮肤商店（用星星兑换，形成星星消耗循环）
- 训练报告（周度专注力趋势曲线）
- 好友挑战（发起对战、异步比拼）
- 亲子模式（更宽松的阈值 + 更大的字号）
