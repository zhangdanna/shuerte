## 2 原创曲目（6 首）

生成方式：`scripts/gen-songs.js`，确定性伪随机（mulberry32）+ 手工设定的调式、和声进行与动机模板。

| id | 曲名 | 调性 | BPM | seed | 和声进行 |
| --- | --- | --- | --- | --- | --- |
| s1a | 纸飞机 | C 大调 | 84 | 11 | I–V–vi–IV |
| s1b | 雨后 | D 大调 | 76 | 23 | I–vi–IV–V |
| s2a | 旋转木马 | F 大调 | 100 | 37 | I–IV–V–I |
| s2b | 旧唱片 | a 小调 | 92 | 41 | i–VI–iv–v |
| s3a | 齿轮 | d 小调 | 118 | 53 | i–VII–VI–v |
| s3b | 夜航 | e 小调 | 112 | 67 | i–iv–VII–v |

**为什么可以主张独立创作**

1. 旋律不是"参考某首歌改编"，而是由算法在给定的调式与和声约束下逐音生成；
2. 同一份 seed + 参数永远产出同一结果，可复现、可审计；
3. 生成过程与参数全部在本仓库里（`SPECS` / `HOOKS` / `buildPhrase` / `removeFriction`），任何人可以重跑验证。

**仍需注意的边界**

算法生成不等于"绝对不会撞"。旋律撞句仍可能被主张实质性相似，所以：

- 每次改动 `HOOKS` / `SPECS` 后必须跑 `node scripts/audio-similarity.js`；
- 该脚本把旋律压成音程串（移调不变量）两两比对，**连续 ≥ 8 个音程重合就报警**；
- 当前基线（2026-10-30）：6 首原创曲目全部 PASS，无 ≥8 音重合。

**用的是什么、没用的是什么**

| | 状态 |
| --- | --- |
| 原作旋律骨架 | ✅ 使用（公有领域） |
| 我们的和声进行 | ✅ 自行编配（`classics.ts` 的 `chords`） |
| 我们的低音与配器 | ✅ 自行编配（`walkingBass` + 伴奏引擎） |
| 任何现成录音 | ❌ 未使用 |

> 民歌类（绿袖子、茉莉花）要特别小心：**旋律是公有的，但某个具体的编曲版本不是**。
> 本项目只取最基础的旋律骨架，和声与织体全部自己写，因此不落入任何既有编配的权利范围。

## 4 音效与音色

| 资产 | 合成方式 | 说明 |
| --- | --- | --- |
| `tick` | 1046.5Hz 正弦，70ms，指数衰减 | 倒计时 |
| `click` | 1568Hz + 2093Hz 叠加，90ms | 降级提示音 |
| `error` | 196Hz + 147Hz 叠加，240ms | 点错 |
| `success` | C5-E5-G5-C6 上行 + 长音 | 通关 |
| 演奏音色 | 运行时振荡器（sine/triangle 倍频叠加 + ADSR） | 八音盒 / 钢琴 / 电钢 |

全部由 `scripts/gen-sounds.js` 与 `services/audio.ts` 现场合成，不含任何采样。
不使用 SoundFont、不使用商业音色库，因此不存在「音色库授权」这一类风险。

## 5 红线（新增资产前必读）

- ❌ 流行歌曲、影视配乐、游戏配乐（久石让、周杰伦、各类 OST）—— 一律不碰，哪怕只用了 4 小节。
- ❌ 现成录音、采样包、音色库 —— 哪怕标注 CC-BY：署名义务 + 包体膨胀都不划算。
- ❌ 他人的民歌改编编曲（旋律公有 ≠ 编曲公有）。
- ❌ 把有版权的完整旋律写进 `scripts/motif-lib.json` 提交入库（该文件只放"用来比对"的片段，本地维护）。
- ✅ 公有领域原作旋律 + 我们自己重新记谱与编配。
- ✅ 算法生成 + 相似度自查通过。

## 6 验收命令

```bash
node scripts/gen-songs.js            # 重新生成原创曲库
node scripts/analyze-songs.js        # 和声体检：强拍冲突必须为 0
node scripts/analyze-songs.js classics
node scripts/audio-similarity.js     # 旋律相似度：不得出现 ≥8 音重合
```

三项全绿才算改完。判定口径写在各自脚本头部注释里，改口径前先想清楚——那是验收线。
